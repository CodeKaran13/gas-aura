# Rogue Extraction

Rogue Extraction is a top-down sci-fi extraction shooter built in Unreal Engine 5 using C++.

This project is designed as a senior gameplay engineering portfolio piece focused on:

- Unreal Engine C++ architecture
- Component-based gameplay systems
- Data-driven weapons and enemies
- Combat and AI systems
- Extraction shooter gameplay loop
- Multiplayer-aware design

## Status

Pre-production / Core Framework implementation.
